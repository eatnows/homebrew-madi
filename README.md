# homebrew-madi

Homebrew tap for [madi](https://github.com/eatnows/madi), a native Rust code editor built on the [gyeol](https://github.com/eatnows/gyeol) UI toolkit, centered on git worktrees.

## Install

```sh
brew tap eatnows/madi
brew install madi
```

## Update

```sh
brew update
brew upgrade madi
```
